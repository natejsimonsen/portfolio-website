The old version of this site had gradients, glowing orbs, and a scanline. It was fun to build and tiring to look at.

This one is a single column of text. The drawings are SVG, generated at build time: a brush circle on the home page, and a small raked-sand garden that is different for every post.

## How writing gets here

Each post is a Markdown file in a `posts` folder. When a file lands on the main branch, the site rebuilds and the post shows up in the list and the feed. There is no admin page and nothing to log in to.

That is the whole system. Less to maintain means more time to write.
